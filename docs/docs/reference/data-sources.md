# Data sources and privileges

Where each check command reads its data from, what privilege that needs and what it depends on. The privilege is always that of the account the NSClient++ agent (the service) runs as - not the user or monitoring server calling the check: *elevated* means Administrator or LocalSystem on Windows and root on Linux and macOS. *Not determined* means nobody has worked it out yet, not that none is needed.

Commands that are not listed here have not been documented yet; their absence says nothing about the privilege they need. Each command's reference page has the full table, including what each source provides.
