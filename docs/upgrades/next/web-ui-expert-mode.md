**Web UI: "Show advanced" on a module page is now "Expert mode".** Nothing to
do. Expert mode shows every setting the module registers, advanced ones
included, as the schema describes it and without the module's tailored layout:
no setup wizard, no tabs, preview column or presets on its collections, no
fields hidden by the page, and collections shown even while the switch they
depend on is off. Dropdowns and pickers for a value still apply. It is off by
default on modules that have a tailored settings page, and on by default on
modules that do not, where the generic form is the whole page.
