**Web UI: filter the module list by kind.** Nothing to do. The *Modules* page
has a row of groups - Checks, Databases, Containers & VMs, Servers, Clients,
Scripts, Scheduling & results, and Other for a module the UI does not know
(a zip bundle, a script module) - each with the number of modules in it. Pick
one or more to list only those; the choice is kept in the address, so going
back from a module keeps it. A module can be in more than one group: a database
check is a check too.
